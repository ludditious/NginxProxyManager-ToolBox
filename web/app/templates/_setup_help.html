What this app does

This ToolBox backs up your Nginx Proxy Manager setup: proxy hosts, certificates list, users, and related settings. You can download backups, copy them to another server, and restore when something breaks or you move hosts.

Minimum setup: NPM host (IP or hostname only), the port where the admin UI listens (you choose — often 80 or your custom port), and the same email/password you use to sign in to NPM. That runs a configuration backup through the NPM API.

Full backup (optional): also archive NPM’s on-disk data and Let’s Encrypt files. Those live in two folders inside the NPM container (/data and /etc/letsencrypt). You only need the two folder paths below if Settings → automated backup has Include volume archives turned on, or you want restore-to-disk.

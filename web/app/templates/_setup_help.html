What this app does

Snapshots — point-in-time API archives. Backup / Restore — full on-host NPM data for recovery. Synchronize — mirror config to other NPM instances. DR Sync — copy full backups to another ToolBox. All schedule times are UTC.

Source setup: NPM host, admin port, and NPM web login (for Sync and Snapshots). Optional folder paths on Source for full Backup / Restore on this Docker host.

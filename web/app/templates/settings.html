DNS

By default the container uses its normal resolver (Docker / host). Enable custom DNS when NPM hostnames only resolve on your LAN (Pi-hole, router, AdGuard Home, etc.).

Comma-separated IPv4 addresses. Ignored when custom DNS is off.

Host overrides

Use when the NPM hostname on the Master page does not resolve inside Docker, or DNS returns a LAN IP the container cannot reach. Map that hostname to an address the container can open (for example host.docker.internal, the Docker gateway, or the NPM container name). The ToolBox connects to the mapped address but sends an HTTP Host header with your original NPM hostname so the admin API still matches what you configured.

One line per mapping: NPM hostname, then connect address (separated by space, tab, or =). Lines starting with # are ignored. Disabled when the checkbox is off.

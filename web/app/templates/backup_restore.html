Backup / Restore

Backs up NPM on this server — the /data and certificate folders ToolBox can read, plus Docker container info. Restore puts those folders back and restarts the NPM container. Not related to Sync Source. Schedules use UTC.

ToolBox must mount the same host folders as NPM, e.g. -v …/npm/data:/npm-data and -v …/npm/letsencrypt:/npm-letsencrypt, plus -v /var/run/docker.sock:/var/run/docker.sock:ro.

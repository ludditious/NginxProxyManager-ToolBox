Address only — no http:// or port. Prefer a LAN IP if a hostname works in your browser but fails here (Docker DNS may not know internal or split-DNS names). Public proxy hostnames often are not the NPM admin API.

Port 80 or 81 → http://. Port 443 → https://. Other custom ports → http://.

Leave blank to connect to the host above. If the host fails from Docker, enter an alternate reachability address (gateway, container name, or internal DNS name). The NPM host field can stay the name you use for NPM itself.
